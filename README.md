# QuizMaster

QuizMaster is a simple Flask-based quiz management web application.

## Features

- Create quizzes
- Take quizzes
- Submit answers and calculate scores
- View quiz results
- Edit quizzes
- Delete quizzes
- Manage quizzes
- JSON API for quizzes
- Health check endpoint
- Automated tests
- Flake8 code quality checks

## Technology Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON
- Pytest
- Flake8
